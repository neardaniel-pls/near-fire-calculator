# Calculator Guide

Complete guide to all FIRE Calculator features.

## Portfolio Setup

### Current Finances
- **Current Savings**: Total savings/investments you have today
- **Monthly Contribution**: How much you save each month
- **Target FIRE Number**: The amount you need for financial independence

### Investments
Add each investment with:
- **Name**: e.g., "VWCE ETF", "PPR"
- **Type**: ETF, PPR, Stock, Bond, Crypto, etc.
- **Allocation %**: Percentage of portfolio
- **Expected Return**: Annual expected return (%)
- **Volatility**: Annual standard deviation (%)

### Templates
Start with a predefined profile:
- **Conservative**: Lower return, lower volatility
- **Moderate**: Balanced return and risk
- **Aggressive**: Higher return, higher volatility

Or save your own custom template.

## Monte Carlo Simulation

### How It Works
1. Takes your portfolio's weighted return and volatility
2. Generates thousands of random future scenarios
3. Each scenario follows a different path based on random returns
4. Shows probability of reaching your FIRE goal

### Configuration
- **Number of simulations**: 1,000 to 10,000 (more = more accurate but slower)
- **Time horizon**: Years to simulate
- **Confidence level**: 95% is standard

### Reading Results
- **Median path**: The middle scenario
- **Success rate**: % of scenarios where you reach FIRE
- **Confidence bands**: Range of likely outcomes

## Financial Events

Add events that affect your savings trajectory:
- **One-time events**: Inheritance, large purchase, etc.
- **Recurring events**: Annual bonus, rental income, extra expenses
- Each event has a year, amount, and description

## Export

Click **Export PDF** to generate a report with:
- Your portfolio summary
- Projection chart
- Monte Carlo results
- Key statistics

## Tips

- Use conservative return estimates (4-7%) for realistic projections
- Include inflation in your calculations
- Run Monte Carlo multiple times with different assumptions
- Financial events can significantly change your trajectory
