# Quick Start Guide

Get up and running with the FIRE Calculator in 2 minutes.

## Option 1: Online (Recommended)

Visit the GitHub Pages deployment (link in repo description).

## Option 2: Local

### Step 1: Clone
```bash
git clone https://github.com/neardaniel-pls/calculadora-fire.git
cd calculadora-fire
```

### Step 2: Open in Browser
Open `index.html` directly, or use Live Server in VS Code for auto-reload.

### Step 3: Start Planning
1. Enter your current savings and monthly contributions
2. Add your investments with expected return and volatility
3. Run Monte Carlo simulation to test your plan
4. Export a PDF report
