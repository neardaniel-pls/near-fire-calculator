## [1.0.0] - 2026-05-25

### Added
- Monte Carlo simulation with configurable paths and time horizon
- Portfolio management with custom return rates and volatility per asset
- Financial events (one-time and recurring)
- Investment templates (Conservative, Moderate, Aggressive)
- PDF report export
- Bilingual support (Portuguese and English)
- Dark and light theme
- Data persistence via browser localStorage
- Responsive design for desktop and mobile
