# Contributing

1. Fork the repo at https://github.com/neardaniel-pls/calculadora-fire
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Make your changes
4. Push and open a pull request

## Code Style

- Use ES6+ modules
- Keep code in `src/` directory
- Update `locales/en.json` and `locales/pt.json` for any new UI text
- Test in both light and dark themes
- Test in both Portuguese and English

## Commit Messages

Use conventional commits: `feat`, `fix`, `docs`, `refactor`, `chore`
